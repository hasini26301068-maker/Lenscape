# Lenscape

Lenscape is an image-search app where users will be able to search for photos and explore visual ideas by topic. I chose a forest-green and warm-cream colour palette because it feels calm and gives the page a nature-inspired look. I used a large editorial-style heading beside the search panel to make the page feel different from a basic search layout. I also added category chips and an empty-state illustration so the page still feels useful before any search results appear.
